# MERQO পণ্য-পরিভাষা অভিধান · Product Terminology Dictionary (v1.0)

## যেসব ইংরেজি শব্দ ইচ্ছাকৃতভাবে রাখা হয়েছে
বাংলাদেশের ব্যবসায়িক প্রচলিত মিশ্র ব্যবহার — বাংলা করলে অস্বাভাবিক শোনায়:
**POS, MFS, PDF, CSV, SKU, WAC, COGS, bKash/নগদ/রকেট (সেবার নাম), ভ্যাট, রোল, স্টাফ, টোকেন, প্রিভিউ, লেবেল**

## সংখ্যা ও মুদ্রা নিয়ম
- টাকা: `৳` চিহ্ন + ইংরেজি সংখ্যায় হাজার-কমা (`৳1,25,000` — লাখ-কোটি ভারতীয় গ্রুপিং `en-IN`)
- পরিমাণ: দশমিকসহ স্বাভাবিক সংখ্যা (`২.৫` নয় — `2.5 kg`)
- তারিখ: `১৭ সেপ্টেম্বর ২০২৬` প্রদর্শনে; ইনপুটে `2026-09-17`

## যতিচিহ্ন ও ধরন
- বাক্য শেষ: দাঁড়ি (।)
- বাটন: সম্মানসূচক করুন-রূপ (সংরক্ষণ করুন, মুছুন)
- ত্রুটি-বার্তা: কারণ + সমাধান, কখনো শুধু "ব্যর্থ হয়েছে" নয়
- ফাঁকা অবস্থা: "এখনও কোনো পণ্য যোগ করা হয়নি।" + কী করতে হবে

## শব্দ-পরিবার সিদ্ধান্তের ইতিহাস (v1.0 অডিট)
- বকেয়া/বাকি/ডিউ → **বকেয়া**; "বাকি" শুধু কথ্য "বাকিতে" প্রসঙ্গে
- ইনভয়েস/চালান → **চালান** (রসিদ আলাদা ধারণা)
- কাস্টমার/গ্রাহক → **গ্রাহক** (core ত্রুটি-বার্তাসহ সব জায়গায়)
- পরিশোধ/পেমেন্ট → দুটোই আছে, অর্থ ভিন্ন: পরিশোধ = বকেয়া মেটানোর কাজ; পেমেন্ট মাধ্যম = মাধ্যম (নগদ/ব্যাংক/বিকাশ)
